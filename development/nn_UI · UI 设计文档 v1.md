# nn_UI · UI 设计文档 v1.0

> 基于《项目规格书 v1.0》与多轮 UI 讨论整理。本文档是前端开发的直接依据。
> 涉及颜色的地方为**建议值**，可微调，但需保持整体米色系。

## 一、整体布局

```
┌───────────────────────────────────────────────────────────────────────┐
│  nn_UI              ⚙   💾   🖼   ✓                                │  ← 顶栏 h=56
│  (art logo)                                                           │
├───────────────────────────────────────────────────────────────────────┤
│                                                                       │
│                                                                       │
│   ◇   ◇   ◇   ◇   ◇   [+]                                          │  ← 主画布
│   (菱形横向叠放，扑克牌式)                                            │     (可滚动)
│                                                                       │
│                                                                       │
│                                                                       │
│                                                                       │
├───────────────────────────────────────────────────────────────────────┤
│  状态/报错区                                          [缩略图预览]    │  ← 底栏 h=140
└───────────────────────────────────────────────────────────────────────┘
```

**布局参数**：

| 区域 | 高度/尺寸 | 说明 |
|------|----------|------|
| 顶栏 | 56px | 固定，不随滚动 |
| 主画布 | `flex: 1` | 横竖滚动条按需出现；单行时无竖向滚动条 |
| 底栏 | 140px | 左：报错/注释；右：缩略图 |
| 右侧参数面板 | 320px | 点击菱形后从右侧滑入，覆盖画布；默认隐藏 |

**禁止缩放**：画布不支持 Ctrl+滚轮或双指缩放。

**画布引擎**：基于 React Flow 实现。扑克牌式横向叠放由前端为节点计算固定坐标实现；主链相邻菱形之间不渲染 Edge（叠放已表达顺序），但后端 Edge 仍保留用于拓扑排序；分支场景的连线渲染为贝塞尔曲线。

## 三、核心元素

### 3.1 菱形 Layer

**形状**：正方形旋转 45°，固定尺寸 **80×80**（对角线约 113），圆角 4px。

**排列**（扑克牌式）：

```
视角：
  ◇◇◇◇◇◇
```
每个菱形相对前一个：
- 横向间距 `+48px`（部分重叠）
- Z 序：左侧在上（`z-index` 递减）
- 效果：左边的菱形"压"在右边菱形的左角

**内容**（文字保持水平，不跟随旋转）：

| 位置 | 内容 | 字号 |
|------|------|------|
| 上部 | 层类型（`Linear`） | 11px 600 |
| 中部 | 关键参数（`128→64`） | 10px `--text-secondary` |
| 下部 | 序号（`#3`） | 9px `--text-secondary` |
| 右上角 | 错误时显示 ⚠ | 12px `--error` |

**视觉**：
- 背景：线性渐变 `--layer-top` → `--layer-bottom`
- 边框：1px `--layer-border`
- 阴影：`--shadow-soft`
- 悬停：`transform: scale(1.08)`，`transition: 150ms ease-out`，阴影换成 `--shadow-hover`

**错误状态**：
- 菱形边框闪红：`animation: flash-red 0.3s ease-in-out 3`
- 动画：边框色 `--layer-border` → `--error` → `--layer-border`
- 右上角 ⚠ 图标持续显示，直到错误消失

### 3.2 三角形 IO

**Input**：等腰三角形，顶尖向左（◁），尺寸 64×64。

**Output**：等腰三角形，顶尖向右（▷），尺寸 64×64。

- 填充色：`--layer-top` → `--layer-bottom` 渐变
- 边框：1px `--layer-border`
- 阴影与菱形相同
- 悬停：`scale(1.08)`
- 文字水平，居中显示 `Input` / `Output`，以及形状（如 `[1, 28, 28]` 或 `[B, T]`）

### 3.3 Block

**圆矩形**，包裹一组菱形。

- 圆角 16px
- 边框 2px 虚线 `--accent-soft`
- 背景：`rgba(167, 139, 250, 0.06)`
- 内边距 24px（左右各留一个圆形端口的位置）
- 左上角标注 Block 名称（12px 600，`--accent`）

**端口**：
- 左侧中央：圆形端口（直径 16px，填充 `--accent-soft`）
- 右侧中央：圆形端口
- 端口可拖出连线，连到 Block 外部的层

**展开/折叠**：
- 折叠态：圆矩形内只显示 Block 名称 + 内部层数（如 `Transformer Encoder (×6)`）
- 展开态：显示内部所有菱形

### 3.4 加号按钮

**主加号**：主链最右侧，48×48 圆形，`--accent` 背景，白色 `+` 图标。

- 悬停：`scale(1.1)`，阴影加深
- 点击：在按钮右侧弹出「添加层」弹窗

**分支加号**：见 3.5。

### 3.5 分支

**添加分支**：右键某个菱形 → 菜单选「添加分支」→ 弹小输入框问「几个分支」→ 从该菱形右侧伸出 N 条箭头。

**视觉**：

```
       ┌── → [+]                    ← 分支 1（向上偏移）
       │
   ◇ ──┼── → [+]                    ← 分支 2（水平）
       │
       └── → [+]                    ← 分支 3（向下偏移）
```

- 箭头：`--accent-soft` 色，1.5px 线宽，末端带箭头
- 每个箭头末端一个圆形 `+` 按钮（24×24）
- **对称排列**：N 个分支以主链水平线为中心上下对称分布
  - N=2：上、下各 1
  - N=3：上、水平、下
  - N=4：上 2、下 2

**汇合**：分支末端可以通过**拼接层**（见 3.7）汇合回主链。

### 3.6 连线

分支场景下，菱形之间用**曲线**连接（贝塞尔），而非箭头。

- 颜色：`--accent-soft`，1.5px
- 悬停：加粗到 2.5px，颜色 `--accent`
- 主链上的相邻菱形**不用线**（扑克牌叠放已表达顺序）

### 3.7 拼接层（特殊层）

多输出或多分支汇合时使用。

- 形状：菱形，但边框为双线
- 图标：菱形中央显示 `⊕`
- 名称：`Concat`
- 参数：`dim`（拼接维度）

### 3.8 加法层（特殊层）

残差连接 / 多输入逐元素相加时使用。

- 形状：菱形，边框为双线（与 Concat 一致，表示多输入特殊层）
- 图标：菱形中央显示 `+`
- 名称：`Add`
- 参数：无
- 视觉区分：Concat 用 `⊕`，Add 用 `+`，其余样式相同

## 四、交互规范

### 4.1 鼠标操作

| 操作 | 对象 | 行为 |
|------|------|------|
| 左键单击 | 普通层菱形 | 打开右侧参数面板（超参数编辑） |
| 左键单击 | Block 圆矩形 | 打开居中 Block 参数弹窗 |
| 双击 | 普通层菱形 | 同左键单击 |
| 双击 | Block 圆矩形 | 进入 Block 内部子画布 |
| 右键单击 | 任意元素 | 弹出系统菜单（删除、复制、打包等） |
| 拖拽 | 菱形 | 重排顺序（在主链上左右移动） |
| 拖拽 | 圆形端口 | 拉出连线 |
| 悬停 | 任意元素 | 底栏显示对应名称 |

### 4.2 右键系统菜单

**菱形右键**：

- 复制（Ctrl+C）
- 删除（Delete）
- 打包为 Block
- 添加分支
- 查看代码片段
- 查看输入输出形状

**Block 右键**：

- 复制
- 删除
- 展开 / 折叠
- 重命名

**空白画布右键**：

- 添加层
- 粘贴

### 4.3 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+C | 复制选中 |
| Ctrl+V | 粘贴（插到末尾） |
| Ctrl+Z | 撤销 |
| Ctrl+S | 手动保存 |
| Delete | 删除选中 |
| Tab | 在层之间切换焦点 |
| Esc | 关闭弹窗 |

### 4.4 撤销/重做

仅快捷键 Ctrl+Z / Ctrl+Y，**无 UI 按钮**。历史栈 50 步。后续升级再加按钮。

## 五、弹窗规范

### 5.1 右侧参数面板（普通层）

**触发**：左键单击菱形。

**位置**：从右侧滑入，宽 320px，覆盖画布右侧。

**结构**：

```
┌─────────────────────────┐
│ Linear              [×] │  ← 标题栏
├─────────────────────────┤
│ 基本信息                │  ← 分组标题
│ 序号    #3              │
│ 输入形状 [784]          │
│ 输出形状 [64]           │
├─────────────────────────┤
│ 参数                    │
│ in_features    [128]    │  ← 左名右值
│ out_features   [64]     │
│ bias           [✓]      │
├─────────────────────────┤
│ 激活函数                │
│ 类型          [ReLU ▾]  │  ← 默认 ReLU
│ negative_slope [0.01]   │  ← 仅 LeakyReLU 显示
├─────────────────────────┤
│ [恢复默认]              │
└─────────────────────────┘
```

**参数行布局**：
- 左：参数名（12px，`--text-secondary`）
- 右：输入控件（Input / Select / Switch / Slider）
- 行高 36px，行间分隔 1px `--layer-border`

**分组**：
- 基本信息
- 参数（按 PyTorch 文档顺序）
- 激活函数（所有层都显示，默认 ReLU）

**参数非法**：
- 输入框边框变 `--error`
- 下方出现一行红字说明（如「必须为正整数」）
- 底栏报错区同步显示

**实时生效**：任何改动立即同步后端、重新校验、更新代码。无「确定」按钮。

### 5.2 居中弹窗（设置 / Block 参数 / Block 内部 / 训练）

**通用视觉**：
- 遮罩：`rgba(58, 52, 46, 0.35)`，画布**调暗**
- 弹窗：背景 `--bg-panel`，圆角 12px，阴影 `0 20px 60px rgba(0,0,0,0.15)`
- 关闭：右上角 × 或 Esc

**训练完成后**：
- 弹窗询问是否保存训练记录到项目
- 点 × 返回编辑界面

## 六、底栏

### 6.1 左侧：状态/报错/注释

**三种模式，互斥显示**：

1. **默认（无操作）**：显示 `就绪`
2. **悬停某元素**：显示该元素的名称 + 关键参数
   - 悬停菱形 → `Linear · 128→64 · #3`
   - 悬停参数 → `in_features：输入特征维度，必须为正整数`
   - 悬停按钮 → 按钮功能说明
3. **报错**：滚动列表，最多 3 条，多的自动删除（FIFO）

**报错条目**：

```
⚠ 节点 #3 Linear 输入维度不匹配：期望 [784]，收到 [512]
⚠ 节点 #5 Conv2d 输出通道数必须为正整数
```

- 颜色：`--error`（错误）/ `--warning`（警告）
- **不可点击**（后续升级）
- 错误修复后自动消失

**保存提示**：手动保存后，此处短暂显示 `已保存到 ~/projects/xxx.nnproj`，2 秒后消失。

### 6.2 右侧：缩略图

- 固定尺寸 200×120
- 显示整个图的结构缩略图
- 只要能看出有几层即可（菱形→小方块）
- **不可交互**（后续升级）
- 层很多时自动缩小以适应框
- **不可平移**，直接展现整体
